# Search Algorithm and Expert System

## 1. Introduction

This project implements two basic Artificial Intelligence
concepts using Python: Breadth-First Search (BFS) and a
rule-based Expert System.

The BFS program finds a path between two nodes in a graph.
The Expert System provides simple computer troubleshooting
recommendations based on user-input symptoms.

## 2. Requirements

- Python 3
- Python standard library
- No additional libraries required

## 3. How to Use

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the Search Algorithm:

   python search_algorithm.py

5. Run the Expert System:

   python expert_system.py

6. Follow the prompts displayed in the terminal.
